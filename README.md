# Nothi — বাংলা PDF এডিটর

একটা ছোট, ভালোবেসে বানানো টুল: PDF-এ বাংলা/ইংরেজি টেক্সট বসান — আসল ইউনিকোড ফন্টে (Hind Siliguri, Kalpurush, Tinos), তাই এক্সপোর্টের পরেও ভাঙে না বা বক্স (□□□) হয়ে যায় না। কোনো ব্যাকএন্ড নেই — সবকিছু আপনার ব্রাউজারেই চলে।

## চালানো

শুধু `index.html` ডাবল-ক্লিক করলেও কাজ করার কথা, কিন্তু নির্ভরযোগ্যভাবে চালাতে একটা ছোট local server দিয়ে খুলুন (কিছু ব্রাউজার `file://` থেকে সরাসরি ফন্ট/canvas-এর ব্যাপারে খুঁতখুঁতে হতে পারে):

```
cd E:\NothiPDF
python -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন। (VS Code-এ থাকলে "Live Server" extension দিয়েও চালাতে পারেন।)

## প্রজেক্ট গঠন

```
NothiPDF/
  index.html              -- মূল পেজ (markup)
  assets/
    css/styles.css        -- সব styling
    js/
      fonts-data.js       -- এম্বেড করা ফন্টের base64 bytes (বড়, আলাদা রাখা হয়েছে app.js পরিষ্কার রাখতে)
      app.js              -- মূল অ্যাপ্লিকেশন লজিক
```

External library (CDN থেকে লোড হয়, `<script>` ট্যাগে): pdf.js (PDF রেন্ডার), pdf-lib (PDF তৈরি/পরিবর্তন), fontkit (কাস্টম ফন্ট এম্বেড), regenerator-runtime (fontkit-এর একটা নির্ভরতা)।

## বর্তমান ফিচার

- বাংলা+ইংরেজি টেক্সট বসানো, drag/resize করা যায় এমন বক্সে — real Unicode ফন্টে এক্সপোর্ট হয়
- Auto Font: একই বক্সে বাংলা+ইংরেজি মিশিয়ে লিখলে প্রতিটা অংশ নিজে থেকেই ঠিক ফন্টে বসে
- একবার এক্সপোর্ট করা PDF আবার আপলোড করলে সব বক্স ফিরে আসে (rewrite/edit চালিয়ে যাওয়া যায়)
- **PDF Merge** — একাধিক PDF এক ফাইলে জোড়া লাগানো
- **PDF Compress** — পাতাগুলোকে ছবিতে রূপান্তর করে সাইজ কমানো (স্ক্যান করা/ছবি-ভিত্তিক PDF-এর জন্য কার্যকর; টেক্সট-ভিত্তিক PDF-এ টেক্সট সিলেক্ট করার ক্ষমতা হারায় — এটা সব বিনামূল্যে অনলাইন PDF compressor-এরই সীমাবদ্ধতা)

### "আরও টুলস" (নতুন)

- **পাসপোর্ট ছবি / স্বাক্ষর সাইজ** — Teletalk-সহ সরকারি ফর্মের এক্স্যাক্ট স্পেক অনুযায়ী: ছবি ৩০০×৩০০px, স্বাক্ষর ৩০০×৮০px (বা কাস্টম সাইজ), pan/zoom দিয়ে ক্রপ, সাদা/নীল ব্যাকগ্রাউন্ড, JPG কোয়ালিটি স্লাইডার। প্লাস একটা **বেসিক ব্যাকগ্রাউন্ড রিমুভ** — কোনো AI মডেল ছাড়াই, ক্লাসিক্যাল flood-fill অ্যালগরিদম দিয়ে (ছবির চার কোনা থেকে একরঙা/কাছাকাছি-রঙা এলাকা খুঁজে বের করে সাদা/নীল দিয়ে বদলে দেয়)। **সীমাবদ্ধতা**: এটা সেরা কাজ করে যখন আসল ব্যাকগ্রাউন্ড মোটামুটি একরঙা হয় (দেয়াল, পর্দা) — জটিল/বহু-রঙা ব্যাকগ্রাউন্ডে ভালো কাজ নাও করতে পারে। সত্যিকারের AI-ভিত্তিক (মানুষ চিনে নিয়ে বাকি সব বাদ দেওয়া) কাট-আউট একটা বড়, আলাদা ফিচার — নিচের "যা এখনো বাকি" অংশ দেখুন।
- **স্বাক্ষর আঁকুন** — মাউস/আঙুল দিয়ে সরাসরি সই এঁকে PNG (স্বচ্ছ ব্যাকগ্রাউন্ড) বা ৩০০×৮০ JPG (সাদা ব্যাকগ্রাউন্ড, সরকারি ফর্মের জন্য) হিসেবে ডাউনলোড।
- **ছবি → PDF** — একাধিক ছবি একটা PDF-এ রূপান্তর, দুইভাবে: প্রতিটা ছবি আলাদা পাতায়, অথবা সব ছবি এক পাতায় উপরে-নিচে সাজিয়ে (NID-এর সামনে+পেছনে এক পাতায় বসাতে এটাই দরকার)।
- **পাতা ম্যানেজার** — PDF-এর পাতাগুলোর থাম্বনেইল দেখে টেনে-এনে সাজানো (drag & drop), যেকোনো পাতা মুছে ফেলা/ফিরিয়ে আনা, প্রতি পাতা ৯০° করে ঘোরানো, আর নিচে একটা রেঞ্জ (যেমন "1-3") লিখে সেই পাতাগুলো আলাদা PDF হিসেবে বের করে নেওয়া (split)।
- **ওয়াটারমার্ক / পাতা নম্বর / তারিখ** — একসাথে তিনটাই (বা যেকোনো একটা) সব পাতায় বসিয়ে দেওয়া। ওয়াটারমার্ক টেক্সট বাংলা বা ইংরেজি দুটোই সমর্থন করে (আসল embedded Hind Siliguri ফন্ট ব্যবহার করে, তাই বাংলা লিখলেও ভাঙবে না)।

## যা এখনো বাকি (চাইলে পরে যোগ করা যাবে)

আপনি যে বড় তালিকা দিয়েছিলেন তার মধ্যে এগুলো এখনো implement করা হয়নি — কারণ প্রতিটার জন্য আলাদা, ভারী কাজ লাগবে:

- **PDF-এ ছবি/স্বাক্ষর সরাসরি বসানো** (এডিটরের ভেতরেই drag করে) — এখন "ছবি → PDF" আর "স্বাক্ষর আঁকুন" আলাদা টুল হিসেবে কাজ করে (ডাউনলোড করে নিতে হয়); মূল টেক্সট-বক্স এডিটরে ছবিকে একটা বক্সের মতো বসিয়ে move/resize করার ফিচারটা এখনো নেই। এটা মূল এডিটরের কোড ছুঁতে হবে বলে সাবধানে আলাদাভাবে করা দরকার।
- **আসল AI ব্যাকগ্রাউন্ড রিমুভ** (জটিল ব্যাকগ্রাউন্ডেও ভালো কাজ করে) — এখনকারটা ক্লাসিক্যাল অ্যালগরিদম, ভালো কিন্তু সীমিত। আসল AI মডেল (যেমন Google-এর MediaPipe Selfie Segmentation, ফ্রি/commercial-safe লাইসেন্স) ব্যবহার করে মান অনেক বাড়ানো যাবে — কিন্তু এটার জন্য ব্রাউজারে একটা মডেল লোড করতে হবে (কয়েক MB), তাই বাস্তব ব্রাউজারে টেস্ট করা লাগবে।
- **OCR (বাংলা+ইংরেজি) ও Searchable PDF** — Tesseract.js দিয়ে সম্ভব, ব্রাউজারেই চলে, কিন্তু বড় কাজ (ভাষার ডেটা ডাউনলোড, টেক্সট পজিশনিং নিখুঁত করা)।
- **Password-protect PDF** — pdf-lib নিজে এনক্রিপশন সমর্থন করে না; এর জন্য আলাদা লাইব্রেরি (`@cantoo/pdf-lib` এর মতো fork) লাগবে, যাচাই করে বসাতে হবে।
- **PDF ফর্ম ফিল-আপ** — pdf-lib-এর নিজস্ব `getForm()` API দিয়ে সম্ভব, তুলনামূলক সহজ, চাইলে পরে দ্রুত যোগ করা যাবে।
- **Application/Document Package Builder** — একটা wizard যেটা ধাপে ধাপে ছবি+স্বাক্ষর+NID+CV একসাথে জোড়া দেবে; উপরের টুলগুলো (ছবি→PDF + Merge) দিয়েই এখন ম্যানুয়ালি করা যায়, শুধু একটা গাইডেড UI বাকি।

বলবেন কোনটা আগে দরকার — একসাথে সবগুলো না করে ধাপে ধাপে করাই নিরাপদ (প্রতিটা ফিচার আগেরগুলো না ভেঙে যোগ করা লাগে)।

## হোস্ট করবেন কীভাবে (ধাপে ধাপে, খরচ ছাড়া)

এই সাইটে কোনো ব্যাকএন্ড/সার্ভার/বিল্ড-স্টেপ নেই — শুধু static ফাইল (HTML/CSS/JS), তাই হোস্ট করা সবচেয়ে সহজ কাজগুলোর একটা।

**সবচেয়ে সহজ পথ (Vercel/Netlify, ফ্রি):**
1. এই `E:\NothiPDF` ফোল্ডারটাকে একটা GitHub রিপোতে push করুন (`git init`, `git add .`, `git commit`, তারপর GitHub-এ একটা রিপো বানিয়ে push)।
2. [vercel.com](https://vercel.com) বা [netlify.com](https://netlify.com)-এ গিয়ে GitHub দিয়ে সাইন-আপ করুন, ওই রিপো "Import"/"Add new site" করুন।
3. কোনো বিল্ড কমান্ড লাগবে না (Framework: "Other"/"None", Build command: খালি, Output directory: `.` বা root) — সরাসরি deploy হয়ে যাবে।
4. একটা ফ্রি `.vercel.app`/`.netlify.app` সাবডোমেইন সাথে সাথেই পাবেন। নিজের ডোমেইন (যেমন `nothipdf.com`) কিনে যোগ করাও এই প্যানেল থেকেই করা যায় (কয়েক ডলার/বছর, .com.bd হলে দেশীয় রেজিস্ট্রার থেকেও নেওয়া যায়)।

এরপর যেকোনো ভিজিটর সংখ্যা (১০ জন হোক বা ১০ লাখ) এই ফ্রি টায়ারেই চলবে, কারণ সব প্রসেসিং ভিজিটরের নিজের ব্রাউজারে হয় — আপনার হোস্টিং শুধু ফাইলগুলো পাঠায়।

## ব্যবহার মাইলস্টোন (নতুন) + Ads নিয়ে বাস্তব কথা

**যোগ করা হয়েছে**: প্রতিটা সফল ডাউনলোড (মূল এডিটর, Merge, Compress, ছবি→PDF, পাতা ম্যানেজার, স্ট্যাম্প টুলস, ফটো স্টুডিও, স্বাক্ষর) গোনা হয় ব্রাউজারের `localStorage`-এ (`nothi_usage_count`)। প্রতি ৮টা ফাইলে একটা ছোট, বন্ধ-করা-যায় এমন "🎉 আপনি ৮টা ফাইল বানিয়েছেন" টোস্ট মেসেজ দেখায় — এটা **কোনো কিছু বন্ধ করে না**, শুধু একটা বন্ধুত্বপূর্ণ রিমাইন্ডার। যেহেতু কোনো ব্যাকএন্ড/অ্যাকাউন্ট নেই, এটা easily bypass করা যায় (ব্রাউজার ডেটা মুছে ফেললে বা incognito window-এ) — তাই এটাকে "সীমা" না ভেবে "awareness" হিসেবে দেখুন।

**Google AdSense যোগ করতে চাইলে**, এই ধাপগুলো লাগবে (এগুলো আমি করে দিতে পারব না, কারণ এটা আপনার নিজের Google অ্যাকাউন্ট/সাইট-ভিত্তিক):
1. সাইটটা আগে একটা রিয়েল ডোমেইনে হোস্ট করে ফেলুন (উপরের ধাপ অনুযায়ী)।
2. [google.com/adsense](https://www.google.com/adsense/)-এ গিয়ে সাইন-আপ করুন, আপনার সাইটের URL দিন — Google রিভিউ করে approve করবে (কয়েকদিন থেকে কয়েক সপ্তাহ লাগতে পারে, ট্রাফিক/কন্টেন্ট quality দেখে)।
3. Approve হলে আপনি একটা Publisher ID (যেমন `ca-pub-XXXXXXXXXXXXXXXX`) পাবেন — সেটা আমাকে দিলে আমি `index.html`-এ script + ad slot বসিয়ে দেব (কয়েক মিনিটের কাজ)।

**বাস্তব প্রত্যাশা**: নতুন, কম-ট্রাফিক সাইটে AdSense থেকে শুরুতে আয় প্রায় শূন্যের কাছাকাছি হবে — এটা pageview-এর সংখ্যার উপর নির্ভর করে, আর বাংলা-ভাষী অডিয়েন্সের জন্য per-1000-view রেট সাধারণত কম। রিয়েল আয়ের জন্য প্রতিদিন হাজার হাজার ভিজিটর দরকার, যেটা সময় ও মার্কেটিং/SEO নিয়ে আসে। Ads শুরু করার জন্য ভালো (খরচ শূন্য, ট্রাফিক এলে বাড়তি আয়), কিন্তু এটাকে মূল আয়ের উৎস ধরে পরিকল্পনা করবেন না — নিচের payment/account ধাপটাই আসল আয়ের রাস্তা।

## Income/Scaling নিয়ে honest পরামর্শ

**যেটা আছে এখন**: একটা সম্পূর্ণ client-side (ব্রাউজার-শুধু) স্ট্যাটিক সাইট। কোনো সার্ভার, ডেটাবেস, ইউজার অ্যাকাউন্ট, বা পেমেন্ট সিস্টেম নেই।

**"Scaling" মানে এখানে দুই আলাদা জিনিস — কোনটা লাগবে সেটা বুঝে নেওয়া জরুরি:**

1. **অনেক মানুষ একসাথে ব্যবহার করলে সার্ভার লোড** — এখানে এই সমস্যাই নেই। প্রতিটা ভিজিটরের ব্রাউজার নিজেই সব কাজ (PDF processing) করে, আপনার কোনো সার্ভারে চাপ পড়ে না। তাই "১০,০০০ ইউজার একসাথে" এলেও শুধু হোস্টিং (static file serve করা) দরকার — Vercel/Netlify/GitHub Pages-এর ফ্রি টায়ারই যথেষ্ট, প্রায় কোনো খরচ ছাড়াই।

2. **টাকা নেওয়া, অ্যাকাউন্ট রাখা, ব্যবহারের সীমা বেঁধে দেওয়া** — এর জন্য **সত্যিই একটা ব্যাকএন্ড লাগবে**:
   - ইউজার লগইন/অ্যাকাউন্ট (যেমন: Supabase Auth, Clerk, বা Firebase Auth — সহজে বসানো যায়)
   - পেমেন্ট (Stripe Checkout — বাংলাদেশ থেকে হলে SSLCommerz/bKash-ও বিবেচনা করা যায়)
   - কী বিক্রি করবেন তা ঠিক করা: (ক) এককালীন কেনা "Pro" ভার্সন যেটাতে Merge/Compress আনলক থাকে, (খ) মাসিক সাবস্ক্রিপশন, নাকি (গ) ফ্রি + বিজ্ঞাপন।

**আমার সুপারিশ (ধাপে ধাপে):**
1. **এখন**: এই সাইটটা যেকোনো ফ্রি static hosting-এ (Vercel/Netlify) আপলোড করে একটা নিজের ডোমেইন/সাবডোমেইনে দাঁড় করান — সম্পূর্ণ ফ্রি, খরচ শূন্য।
2. **যাচাই করুন**: মানুষ আসলে এটা ব্যবহার করছে কিনা, কী ফিচার সবচেয়ে বেশি চাইছে (Google Analytics/Plausible দিয়ে দেখুন)।
3. **তারপরই** payment/account যোগ করুন — আগে থেকে বানিয়ে রাখলে ব্যবহারকারী না এলে সময় নষ্ট হবে।

এই ধাপ ২-৩ (backend, payment) নিয়ে কাজ করতে চাইলে বলবেন — সেটা এই প্রজেক্টের একটা বড়, আলাদা সংযোজন হবে।
