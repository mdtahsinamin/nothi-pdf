# Nothi — বাংলা PDF এডিটর

বাংলা-প্রথম PDF এডিটর: PDF-এর **আসল লেখা ও ছবি সরাসরি বদলান**, নতুন বাংলা/ইংরেজি লেখা, স্বাক্ষর, হাইলাইট, ফর্ম পূরণ, স্ক্যান করা কাগজ OCR — আসল ইউনিকোড ফন্টে (Hind Siliguri, Kalpurush, Tinos), তাই এক্সপোর্টের পরেও ভাঙে না বা বক্স (□□□) হয়ে যায় না। কোনো ব্যাকএন্ড নেই — সবকিছু ব্যবহারকারীর ব্রাউজারেই চলে, ফাইল কোথাও আপলোড হয় না।

## চালানো

একটা ছোট local server দিয়ে খুলুন (ES module, service worker আর ফন্টের জন্য `file://` চলবে না):

```
cd D:\F\KalomPDF
python -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন। (VS Code-এ "Live Server" extension দিয়েও চলে।)

## প্রজেক্ট গঠন

```
index.html                -- মূল পেজ (ল্যান্ডিং + এডিটর + সব টুলের modal)
manifest.webmanifest      -- PWA: "Add to Home screen" / ইনস্টল
sw.js                     -- service worker: অফলাইনে চালানো (অ্যাপ ফাইল + CDN লাইব্রেরি ক্যাশ)
assets/
  css/styles.css          -- পুরো ডিজাইন সিস্টেম (লাইট/ডার্ক থিম, রেসপন্সিভ)
  img/icon.svg, icon-*.png
  js/
    fonts-data.js         -- এম্বেড করা ফন্টের base64 bytes
    core.js               -- শেয়ার্ড ভিত্তি: DOM রেফারেন্স, থিম, toast, modal, নাম/পাসওয়ার্ড ডায়ালগ,
                             ডাউনলোড, IndexedDB (autosave), lazy-load (পাসওয়ার্ড লাইব্রেরি, OCR)
    editor.js             -- মূল এডিটর: আসল লেখা/ছবি এডিট, নতুন লেখা/ছবি/আকৃতি, multi-select,
                             undo/redo, autosave, ফর্ম, পাতা-OCR, পাতা যোগ/মোছা/ঘোরানো, পাতা নম্বর, export
    pdf-text-remove.js    -- PDF content stream পার্স করে নির্দিষ্ট জায়গার আসল লেখা/ছবি সত্যিই মুছে ফেলে
    tools-pdf.js          -- Merge, Compress, ছবি→PDF, পাতা ম্যানেজার, স্ট্যাম্প, পাসওয়ার্ড, OCR টুল
    tools-image.js        -- ফটো/স্বাক্ষর স্টুডিও, NID জোড়া, স্বাক্ষর আঁকার প্যাড
```

কোনো বিল্ড স্টেপ নেই। External library (CDN, নির্দিষ্ট ভার্সনে পিন করা): pdf.js 3.11.174 (রেন্ডার/লেখা খোঁজা), pdf-lib 1.17.1 (PDF তৈরি/পরিবর্তন), fontkit (ফন্ট এম্বেড), আর দরকার হলে তখনই লোড হয় — `@cantoo/pdf-lib` 2.11.1 (পাসওয়ার্ড দেওয়া/খোলা) ও tesseract.js 5.1.1 (বাংলা+ইংরেজি OCR)।

## ফিচার

### এডিটর
- **আসল লেখা এডিট (এডিট মোড, `E`)** — PDF-এর যেকোনো লাইন/অনুচ্ছেদে ক্লিক করলে সেটা এডিটযোগ্য বক্স হয়ে যায়: ফন্ট সাইজ, বোল্ড, serif/sans, **রং** আর লাইনের ফাঁক নিজে থেকেই মেলে, নতুন লেখা ঠিক আসল baseline-এ বসে। এক্সপোর্টের সময় পুরনো glyph-গুলো PDF-এর content stream থেকে **সত্যিই মুছে ফেলা হয়** (শুধু সাদা রং দিয়ে ঢাকা নয় — তাই কপি/সার্চ করলে পুরনো লেখা আর আসে না), বাকি সব লেখা নিজের জায়গায় অটুট থাকে। যে লেখা মোছা যায় না (ছবির ভেতরের লেখা, Form XObject, Type3 ফন্ট) সেখানে পাতার নিজের ব্যাকগ্রাউন্ড রঙে ঢেকে দেওয়া হয়। শুধু ক্লিক করে কিছু না বদলালে আসল লেখা অপরিবর্তিত থাকে।
- **বাংলা লেখা মেরামত** — অনেক PDF বাংলা visual order-এ রাখে (ি/ে/ৈ আগে, ো/ৌ ভাঙা); সেটা শনাক্ত করে সঠিক ইউনিকোডে ফেরানো হয়। পুরনো Bijoy/SutonnyMJ ফন্টের লেখা চিনে আলাদা করে দেখানো হয় (নতুন করে টাইপ বা বক্সের OCR বাটন দিয়ে পড়ানো যায়)।
- **আসল ছবি এডিট** — PDF-এর ছবিতে ক্লিক করে সরান, বড়-ছোট করুন, অন্য ছবি দিয়ে বদলান বা মুছুন (আসল ছবি ফাইল থেকে সরিয়ে দেওয়া হয়)।
- **স্ক্যান করা পাতা** — লেখা না পেলে "OCR করে লেখা খুঁজুন" — বাংলা+ইংরেজি লাইন খুঁজে বের করে, তারপর একই ভাবে ক্লিক করে বদলানো যায়।
- **নতুন লেখা (`T`)**, **ছবি/স্বাক্ষর**, **আকৃতি** — সাদা করে মোছা (`W`), হাইলাইট (`H`), আয়তক্ষেত্র (`R`), বৃত্ত, লাইন, টিক ✓, ক্রস ✗।
- **ফর্ম পূরণ** — পূরণযোগ্য PDF ফর্মের ঘরে সরাসরি লেখা (বাংলাসহ), চেকবক্স, রেডিও, ড্রপডাউন।
- **একাধিক বক্স** — Shift+ক্লিক বা টেনে (নির্বাচন মোড, `V`) বাছাই, একসাথে সরানো/স্টাইল/মোছা; Ctrl+A/C/V/D, তীর-কী দিয়ে সূক্ষ্মভাবে সরানো।
- **Undo/Redo** (Ctrl+Z / Ctrl+Y) — পাতা যোগ/মোছার মতো কাজসহ।
- **পাতা** — সাইডবার থেকে পাতা ঘোরানো, কপি, ফাঁকা পাতা যোগ, মোছা, টেনে সাজানো, অন্য PDF জোড়া; **পাতা নম্বর বসানো** (বাংলা/ইংরেজি অঙ্ক, ধরন, অবস্থান, পাতার সীমা)।
- **নেভিগেশন** — মাউস/টাচপ্যাড স্ক্রল পাতার শেষে গিয়ে পরের পাতায় চলে যায়, ↑↓ / PageUp/PageDown / Home/End, পাতা নম্বর লিখে সরাসরি যাওয়া, Ctrl+স্ক্রল জুম।
- **Autosave** — প্রতিটা এডিট ব্রাউজারের IndexedDB-তে সেভ হয়; ট্যাব বন্ধ/রিফ্রেশ হলে ল্যান্ডিং পেজে "অসমাপ্ত কাজ" থেকে চালিয়ে যাওয়া যায়।
- **পাসওয়ার্ড দেওয়া PDF** সরাসরি খোলা যায় (পাসওয়ার্ড চেয়ে নেয়); শুধু owner-restriction থাকলে নিজে থেকেই খুলে যায়।
- **ডাউনলোডের আগে ফাইলের নাম** বদলানো যায় (সব টুলে), Ctrl+S দিয়ে এক্সপোর্ট। এক্সপোর্ট করা PDF আবার আপলোড করলে সব বক্স ফিরে আসে।

### আরও টুলস
PDF মার্জ · কমপ্রেস · ছবি→PDF · পাতা ম্যানেজার (সাজানো/মোছা/ঘোরানো/split) · ওয়াটারমার্ক/পাতা নম্বর/তারিখ · **পাসওয়ার্ড দিন/খুলুন** (AES-256, প্রিন্ট/কপি নিষেধ) · **OCR** (স্ক্যান PDF/ছবি → সার্চযোগ্য PDF + .txt) · পাসপোর্ট ছবি/স্বাক্ষর সাইজ (Teletalk) · স্বাক্ষর আঁকা · NID সামনে+পেছন জোড়া।

### অন্যান্য
নতুন ডিজাইন (লাইট/ডার্ক, মোবাইল-ফ্রেন্ডলি), ল্যান্ডিং পেজ থেকে এক ক্লিকে যেকোনো টুল, **PWA** (ইনস্টল করা যায়, প্রথমবার খোলার পর ইন্টারনেট ছাড়াও চলে), বড় PDF-এ থাম্বনেইল দেখা গেলে তবেই রেন্ডার হয়।

## সীমাবদ্ধতা (সৎভাবে)

- **নতুন লেখার ফন্ট** — আসল PDF-এর ফন্ট সাধারণত আংশিক (subset) এম্বেড থাকে, তাই এডিট করা লেখা আমাদের তিনটা ফন্টের সবচেয়ে কাছেরটায় বসে (সাইজ/রং/বোল্ড/অবস্থান মেলে, তবে হুবহু একই ফন্ট নাও হতে পারে)।
- **কাত/ঘোরানো লেখা** এডিট মোডে আসে না (সোজা লেখা আসে)।
- **Bijoy/SutonnyMJ → ইউনিকোড রূপান্তর** এখনো নেই — এসব লেখা নতুন করে টাইপ বা OCR করতে হয়।
- OCR প্রথমবার ~১৫MB ভাষার ডেটা নামায় (পরে ব্রাউজার ক্যাশ থেকে চলে); ছোটখাটো ভুল থাকতে পারে।
- আগের এক্সপোর্টে আঁকা হাইলাইট/আকৃতি পরে বদলালে পুরনোটার জায়গা সাদা করে ঢাকা হয় (আঁকা জিনিস content stream থেকে আলাদা করে মোছা হয় না)।
- **আসল AI ব্যাকগ্রাউন্ড রিমুভ** (ফটো স্টুডিওতে) এখনো ক্লাসিক্যাল অ্যালগরিদম।

## হোস্ট করবেন কীভাবে (ধাপে ধাপে, খরচ ছাড়া)

এই সাইটে কোনো ব্যাকএন্ড/সার্ভার/বিল্ড-স্টেপ নেই — শুধু static ফাইল (HTML/CSS/JS), তাই হোস্ট করা সবচেয়ে সহজ কাজগুলোর একটা।

**সবচেয়ে সহজ পথ (Vercel/Netlify, ফ্রি):**
1. এই প্রজেক্ট ফোল্ডারটাকে একটা GitHub রিপোতে push করুন (`git init`, `git add .`, `git commit`, তারপর GitHub-এ একটা রিপো বানিয়ে push)।
2. [vercel.com](https://vercel.com) বা [netlify.com](https://netlify.com)-এ গিয়ে GitHub দিয়ে সাইন-আপ করুন, ওই রিপো "Import"/"Add new site" করুন।
3. কোনো বিল্ড কমান্ড লাগবে না (Framework: "Other"/"None", Build command: খালি, Output directory: `.` বা root) — সরাসরি deploy হয়ে যাবে।
4. একটা ফ্রি `.vercel.app`/`.netlify.app` সাবডোমেইন সাথে সাথেই পাবেন। নিজের ডোমেইন (যেমন `nothipdf.com`) কিনে যোগ করাও এই প্যানেল থেকেই করা যায় (কয়েক ডলার/বছর, .com.bd হলে দেশীয় রেজিস্ট্রার থেকেও নেওয়া যায়)।

এরপর যেকোনো ভিজিটর সংখ্যা (১০ জন হোক বা ১০ লাখ) এই ফ্রি টায়ারেই চলবে, কারণ সব প্রসেসিং ভিজিটরের নিজের ব্রাউজারে হয় — আপনার হোস্টিং শুধু ফাইলগুলো পাঠায়।

## ব্যবহার মাইলস্টোন (নতুন) + Ads নিয়ে বাস্তব কথা

**যোগ করা হয়েছে**: প্রতিটা সফল ডাউনলোড (মূল এডিটর, Merge, Compress, ছবি→PDF, পাতা ম্যানেজার, স্ট্যাম্প টুলস, ফটো স্টুডিও, স্বাক্ষর) গোনা হয় ব্রাউজারের `localStorage`-এ (`nothi_usage_count`)। প্রতি ৮টা ফাইলে একটা ছোট, বন্ধ-করা-যায় এমন "🎉 আপনি ৮টা ফাইল বানিয়েছেন" টোস্ট মেসেজ দেখায় — এটা **কোনো কিছু বন্ধ করে না**, শুধু একটা বন্ধুত্বপূর্ণ রিমাইন্ডার। যেহেতু কোনো ব্যাকএন্ড/অ্যাকাউন্ট নেই, এটা easily bypass করা যায় (ব্রাউজার ডেটা মুছে ফেললে বা incognito window-এ) — তাই এটাকে "সীমা" না ভেবে "awareness" হিসেবে দেখুন।

**Google AdSense যোগ করতে চাইলে**, এই ধাপগুলো লাগবে (এগুলো আমি করে দিতে পারব না, কারণ এটা আপনার নিজের Google অ্যাকাউন্ট/সাইট-ভিত্তিক):
1. সাইটটা আগে একটা রিয়েল ডোমেইনে হোস্ট করে ফেলুন (উপরের ধাপ অনুযায়ী)।
2. [google.com/adsense](https://www.google.com/adsense/)-এ গিয়ে সাইন-আপ করুন, আপনার সাইটের URL দিন — Google রিভিউ করে approve করবে (কয়েকদিন থেকে কয়েক সপ্তাহ লাগতে পারে, ট্রাফিক/কন্টেন্ট quality দেখে)।
3. Approve হলে আপনি একটা Publisher ID (যেমন `ca-pub-XXXXXXXXXXXXXXXX`) পাবেন — সেটা আমাকে দিলে আমি `index.html`-এ script + ad slot বসিয়ে দেব (কয়েক মিনিটের কাজ)।

**বাস্তব প্রত্যাশা**: নতুন, কম-ট্রাফিক সাইটে AdSense থেকে শুরুতে আয় প্রায় শূন্যের কাছাকাছি হবে — এটা pageview-এর সংখ্যার উপর নির্ভর করে, আর বাংলা-ভাষী অডিয়েন্সের জন্য per-1000-view রেট সাধারণত কম। রিয়েল আয়ের জন্য প্রতিদিন হাজার হাজার ভিজিটর দরকার, যেটা সময় ও মার্কেটিং/SEO নিয়ে আসে। Ads শুরু করার জন্য ভালো (খরচ শূন্য, ট্রাফিক এলে বাড়তি আয়), কিন্তু এটাকে মূল আয়ের উৎস ধরে পরিকল্পনা করবেন না — নিচের payment/account ধাপটাই আসল আয়ের রাস্তা।

## Income/Scaling নিয়ে honest পরামর্শ

**যেটা আছে এখন**: একটা সম্পূর্ণ client-side (ব্রাউজার-শুধু) স্ট্যাটিক সাইট। কোনো সার্ভার, ডেটাবেস, ইউজার অ্যাকাউন্ট, বা পেমেন্ট সিস্টেম নেই।

**"Scaling" মানে এখানে দুই আলাদা জিনিস — কোনটা লাগবে সেটা বুঝে নেওয়া জরুরি:**

1. **অনেক মানুষ একসাথে ব্যবহার করলে সার্ভার লোড** — এখানে এই সমস্যাই নেই। প্রতিটা ভিজিটরের ব্রাউজার নিজেই সব কাজ (PDF processing) করে, আপনার কোনো সার্ভারে চাপ পড়ে না। তাই "১০,০০০ ইউজার একসাথে" এলেও শুধু হোস্টিং (static file serve করা) দরকার — Vercel/Netlify/GitHub Pages-এর ফ্রি টায়ারই যথেষ্ট, প্রায় কোনো খরচ ছাড়াই।

2. **টাকা নেওয়া, অ্যাকাউন্ট রাখা, ব্যবহারের সীমা বেঁধে দেওয়া** — এর জন্য **সত্যিই একটা ব্যাকএন্ড লাগবে**:
   - ইউজার লগইন/অ্যাকাউন্ট (যেমন: Supabase Auth, Clerk, বা Firebase Auth — সহজে বসানো যায়)
   - পেমেন্ট (Stripe Checkout — বাংলাদেশ থেকে হলে SSLCommerz/bKash-ও বিবেচনা করা যায়)
   - কী বিক্রি করবেন তা ঠিক করা: (ক) এককালীন কেনা "Pro" ভার্সন যেটাতে Merge/Compress আনলক থাকে, (খ) মাসিক সাবস্ক্রিপশন, নাকি (গ) ফ্রি + বিজ্ঞাপন।

**আমার সুপারিশ (ধাপে ধাপে):**
1. **এখন**: এই সাইটটা যেকোনো ফ্রি static hosting-এ (Vercel/Netlify) আপলোড করে একটা নিজের ডোমেইন/সাবডোমেইনে দাঁড় করান — সম্পূর্ণ ফ্রি, খরচ শূন্য।
2. **যাচাই করুন**: মানুষ আসলে এটা ব্যবহার করছে কিনা, কী ফিচার সবচেয়ে বেশি চাইছে (Google Analytics/Plausible দিয়ে দেখুন)।
3. **তারপরই** payment/account যোগ করুন — আগে থেকে বানিয়ে রাখলে ব্যবহারকারী না এলে সময় নষ্ট হবে।

এই ধাপ ২-৩ (backend, payment) নিয়ে কাজ করতে চাইলে বলবেন — সেটা এই প্রজেক্টের একটা বড়, আলাদা সংযোজন হবে।
